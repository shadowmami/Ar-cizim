Supabase Bağlantısı Henüz Girilmedi

Ziyaretçi kayıtlarının aktif olması için şu 3 kısa adımı tamamlayın:

  1. Ücretsiz bir Supabase projesi açıp supabase-kurulum.sql dosyasındaki kodları SQL Editor içinde çalıştırın.
  2. Supabase Authentication → Users → Add User bölümünden kendinize bir Admin e-posta ve şifresi oluşturun.
  3. Proje URL ve anon public anahtarınızı ayarlar.js içine yapıştırıp yayin-hazirla.bat dosyasını çalıştırın.
